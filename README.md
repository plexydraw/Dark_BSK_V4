## [ • ] Installation

```bash
git clone https://github.com/PlexyDraw/Dark_BSK_V4.1.git
cd Dark_BSK_V4.1
```

## [ • ] Commands

| Command | Description |
|---|---|
| `search` | Perform a search |
| `update proxies` | Refresh the proxy list |
| `back` | Return to the beginning |
| `exit` | Exit Dark BSK |

## [ • ] Requirements

- Python 3.10+
- Windows (uses `win32api` for console setup)
- Internet connection for proxy fetching
